# Sales, Deliveries & Invoices setup

1. Open Supabase Dashboard → SQL Editor.
2. Run `09_SALES_DELIVERIES_INVOICES_SETUP.sql` once.
3. Deploy the updated app files.
4. Open **Sales** as the administrator.

The module includes draft invoices, delivery notes, premium PDFs, payments, outstanding balances, automatic overdue status, private document storage and administrator-only RLS policies.
